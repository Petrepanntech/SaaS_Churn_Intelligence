Statistical Baseline: 5,000 Accounts audited via SQLite

Underlying SQL CTE Logic (Script 04)

Empirical segmentation query generating priority financial rank

WITH scoring AS (
    SELECT account_id, company_name, monthly_charges,
           CASE WHEN support_tickets_last_30d >= 4 THEN 'Product Friction'
                WHEN last_login_days_ago >= 14 THEN 'Inactivity Cliff'
                ELSE 'Renewal Exposure' END AS trigger_flag
    FROM accounts WHERE churn_status = 0
)
SELECT account_id, company_name, monthly_charges, trigger_flag,
       DENSE_RANK() OVER (ORDER BY monthly_charges DESC) AS financial_priority
FROM scoring WHERE trigger_flag != 'Renewal Exposure' LIMIT 10;
